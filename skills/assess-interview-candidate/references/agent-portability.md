# Agent 与操作系统兼容说明

## 核心原则

核心工作流按能力描述，不绑定某个 Agent 的工具名。宿主只要能够读取本地文件、运行 Python 3.10 及以上版本，并对输入 PDF 完成文字与视觉两类检查，就可以生成完整报告。

`agents/` 下的宿主元数据是可选适配层。缺少这些文件或宿主不识别这些文件时，直接读取 `SKILL.md` 并按相对路径加载 `references/`、`scripts/`、`assets/` 和 `evals/`。

## 路径与命令

- 从当前 `SKILL.md` 所在目录解析 `<skill-dir>`，不要假设 Skill 位于固定的用户目录、项目目录或全局安装目录。
- Python 脚本内部使用 `pathlib`。向脚本传递路径时，把完整路径作为一个参数；路径包含空格、中文或其他非 ASCII 字符时也遵守这一点。
- `<python>` 是占位符。Windows 可依次检查 `py -3`、`python`；macOS 与 Linux 可依次检查 `python3`、`python`。实际解释器必须是 Python 3.10 或更高版本。
- 命令示例中的 `/` 只用于表达相对目录层级。宿主应使用自身文件 API 或外壳接受的路径形式，不手工拼接平台专用分隔符。
- 不依赖 Bash、Zsh、PowerShell 或 `cmd.exe` 的续行、变量展开、管道和重定向语法。需要运行脚本时，优先把程序和每个参数作为独立参数交给宿主执行接口。

## 能力映射

| 工作需要 | 可接受实现 | 缺失时处理 |
| --- | --- | --- |
| 本地文件读取与写入 | Agent 文件 API、标准文件工具或 Python 脚本 | 无法安全读写时停止，不创建案件 |
| PDF 文字提取 | 任意能够保留页码或位置线索的本地解析器 | 报告提取缺口，不凭视觉记忆补写 |
| PDF 逐页视觉检查 | Agent 视觉能力、PDF 渲染器或人工逐页复核 | 以 `PDF_VISUAL_CHECK_UNAVAILABLE` 停止最终报告 |
| 简历头像提取 | PDF 嵌入图片提取器，或页面渲染后的本地裁切 | 记录 `extraction_unavailable`；不从外部来源补图 |
| 当前岗位资料核验 | 宿主可用的浏览器、搜索或网页读取能力 | 关闭该可选分支，并标明岗位研究时效限制 |
| 候选人公开职业证据核验 | 获得允许后的网页能力 | 没有权限或无法确认身份时关闭该分支，不扣分 |
| HTML 交互检查 | 浏览器自动化或人工打开本地 HTML | 自动化不可用时执行人工检查，并说明验证方式 |

不得为了补足宿主能力而上传简历、报告或候选人资料到未经用户批准的远程服务。头像确认只比较原始 PDF 页面与本地提取结果，不调用人脸识别、公开头像搜索或跨来源相似度服务。

## Windows、macOS 与 Linux 注意事项

- 所有 JSON、Markdown 与 HTML 文件使用 UTF-8；生成的 HTML 自包含，不依赖外部字体、脚本或样式。
- 文件名生成器会替换三个系统中不安全的字符，并处理 Windows 保留设备名。
- POSIX 权限位在 Windows 上可能不会产生相同效果；这不改变“只写用户批准目录、不覆盖既有案件、不通过网络发送资料”的安全边界。
- 浏览器可能禁用 `localStorage`。页面应继续显示和允许当前会话记录，并在页面上明确本机保存不可用；不得改用远程存储兜底。
